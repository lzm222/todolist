# 作业记录 → 作业清单导入 JSON

## 适用场景

用户手里有一段任意形态的作业记录，希望把它变成「作业清单」应用能识别的导入内容。典型输入：

- 微信/QQ 群里老师发的文字通知，格式随意（「今天数学：卷子P12-14，语文背课文第三段」）
- 拍照/截图后 OCR 出来的不规则文字
- 语音转写的口语记录（「数学有两项，一是练习册，二是订正」）
- 自己的草稿笔记、表格、Markdown 列表
- 其他 AI 生成的作业总结

只要其中含有「哪些科目、每科有哪些作业」的信息，本 skill 就适用。

## 目标格式（必须严格产出）

「作业清单」App 只接受下面这一种 JSON 结构：

```json
{
  "date": "2025-06-01",
  "subjects": [
    { "name": "数学", "items": ["练习册 P12-14", "订正卷子"] },
    { "name": "语文", "items": ["背诵《岳阳楼记》第三段"] }
  ]
}
```

字段约束（违反任何一条，App 都会拒绝导入并报错）：

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| 顶层 | 对象 `{}` | 必须是对象；也支持用数组 `[{...}, {...}]` 一次导入多天 |
| `date` | 字符串 | 必填。格式 **严格为** `yyyy-MM-dd`，且必须是真实存在的日期（`2025-02-30` 非法） |
| `subjects` | 数组 | 必填、非空 |
| `subjects[].name` | 字符串 | 必填、去空格后非空。就是科目名，如「数学」 |
| `subjects[].items` | 字符串数组 | 必填。每个元素是一条作业内容；空字符串会被 App 自动跳过 |

补充说明：

- 同一个科目只需出现**一次**，把该科所有条目放在同一个 `items` 数组里。
- 数组顺序即显示顺序，请保持原记录的先后次序。
- 不要添加 `note`、`done`、`id` 等额外字段——App 会忽略它们，但容易让用户误以为生效了。

## 执行步骤

1. **确定日期**
   - 记录里若写明日期（「6月1日的作业」「明天要交」），换算成具体 `yyyy-MM-dd`。
   - 若完全没有日期信息，**默认取今天**，并在输出前用一句话说明「已默认按今天 YYYY-MM-DD 处理」。
   - 若日期有歧义（如「下周三」），先向用户确认；无法确认则取今天并说明。

2. **抽取科目**
   - 识别每一条作业属于哪一科。常见形式：科目标题（「数学：」）、前缀（「数学作业」）、分组段落。
   - 科目名做归一化：去掉「作业」「的作业」「科」等尾巴，统一为最短学科名（「数学作业」→「数学」，「语文科」→「语文」）。
   - 无法判断科目的条目，统一归入 `「其他」`，不要丢弃。

3. **拆分条目**
   - 一条作业 = 一个 `items` 元素。用「，」「、」「；」「1.」「-」「①」等分隔符拆分。
   - 每条只保留**一个可执行动作**：如果一句里含两个动作（「做完练习册并订正」），拆成两条。
   - 保留关键细节：页码、题号、篇名、数量、提交形式。
   - 去掉口语填充（「记得」「大家」「请务必」「哈」）和表情符号。

4. **清洗文本**
   - 去除首尾空白；去掉条目开头多余的「1.」「①」「-」等编号符号。
   - 不要在文本里塞换行符。
   - 不改写作业语义：不合并、不概括、不"优化"表述。

5. **自检**
   - 日期是 `yyyy-MM-dd` 且真实存在
   - 每个科目名非空且不重复
   - 每个 `items` 数组非空且元素都是字符串
   - JSON 可以被解析（引号配对、无尾随逗号、中文引号已换成英文引号）

6. **输出**
   - 只输出一段 JSON，放在 ```json 代码块里，方便用户整段复制。

## 约束边界

- **不虚构作业**：记录里没有的内容绝不补全。信息缺失就保留原样或标注「（内容不清）」。
- **不跨科目合并**：即使同一份卷子涉及两科，也分别写在各自科目下。
- **不删减条目**：宁可多一条也不要漏一条。
- **不输出解释性文字进 JSON**：JSON 之外可以有一句日期说明，JSON 之内只有作业内容。
- **不改变"科目"语义**：不要把「数学」改成「数学作业」，也不要把「练习册」当成科目名。
- **不做完成状态标记**：导入的都是未完成作业，本 skill 不处理 `isDone`。

## 期望输出

一段可直接粘贴进 App「导入」对话框的 JSON。示例：

输入（用户给的原始记录）：

```
今天作业 数学：练习册P12-14、订正昨天的卷子
语文 背诵岳阳楼记第三段 作文一篇
英语 unit5单词默写
```

输出：

```json
{
  "date": "2025-06-01",
  "subjects": [
    { "name": "数学", "items": ["练习册 P12-14", "订正昨天的卷子"] },
    { "name": "语文", "items": ["背诵《岳阳楼记》第三段", "作文一篇"] },
    { "name": "英语", "items": ["Unit 5 单词默写"] }
  ]
}
```

## 反例（这些会被 App 拒绝或产生错误结果）

```json
{
  "date": "2025/6/1",
  "subjects": [
    { "name": "数学作业", "items": "练习册P12-14" }
  ]
}
```

问题：日期用了 `/` 分隔（必须是 `-`）；科目名带多余的「作业」后缀；`items` 是字符串而不是数组。
